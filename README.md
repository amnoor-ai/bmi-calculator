# 🧮 BMI Calculator

A Body Mass Index (BMI) calculator that determines a user's BMI based on height and weight and categorizes the result.

## 📌 Description
This application calculates Body Mass Index using user-provided height and weight inputs. After calculating the BMI value, the program also determines the health category (Underweight, Normal weight, Overweight, or Obese) and displays the result instantly.

## 🚀 Features
- Accepts height and weight input
- Calculates BMI instantly
- Displays BMI value
- Shows health category:
  - Underweight
  - Normal weight
  - Overweight
  - Obese
- Real-time DOM updates

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 🧠 What I Learned
- Handling user input
- Number calculations and formulas
- Conditional statements (if/else)
- Dynamic DOM manipulation

## 📏 BMI Formula
BMI = weight (kg) / (height (m) × height (m))
